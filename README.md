# TechnologyCompanyWebsite

A responsive multi-page website for a software and technology company. Built as an individual HTML, CSS and JavaScript practical project.

## Developer
**Osuh Ebubechukwu Gabriel**

## Pages
- `index.html` — Home page
- `about.html` — Company background, mission, vision and developer information
- `services.html` — Software and technology services
- `contact.html` — Contact details and a JavaScript-validated contact form

## Project structure
```text
TechnologyCompanyWebsite/
├── index.html
├── about.html
├── services.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Technologies used
- **HTML5:** Semantic page structure, navigation, headings, links and form elements.
- **CSS3:** External stylesheet, layout, typography, spacing, colours and responsive media queries.
- **Flexbox:** Navigation, action buttons, footer and several content alignments.
- **CSS Grid:** Main page layouts, service cards and information sections.
- **JavaScript:** Mobile navigation, automatic copyright year and contact-form validation.

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Navigate between the Home, About, Services and Contact pages.

You can also open the folder in Visual Studio Code and use the Live Server extension if it is installed. Live Server is optional.

## Important notes
- The email address and telephone number on the Contact page are sample details. Replace them with real contact details before publishing.
- The contact form performs browser-side validation only. It does not send or store messages. Connect a backend or form service if real message submission is required.
- Test the website on mobile, tablet and desktop screen sizes before submission.

## Deployment
The project can be uploaded to a GitHub repository and deployed as a static website using Netlify, Render or another static hosting provider.
